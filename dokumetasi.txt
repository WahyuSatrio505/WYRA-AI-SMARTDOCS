2. TEKNOLOGI & TOOLS UTAMA
---------------------------------------------------------
1. AI & RAG Stack:
   - LangChain: Orkestrator yang menghubungkan AI dengan dokumen.
   - Ollama: Menjalankan model AI secara lokal tanpa internet.
   - ChromaDB: Vector Database untuk menyimpan "ingatan" dokumen.
   - Llama 3.2: Otak / LLM utama pembuat jawaban.
   - Nomic Embed Text: Model embedding untuk pencarian kontekstual dokumen.

2. Backend Stack:
   - Python & FastAPI: Framework super cepat untuk melayani API.
   - Uvicorn: Server web untuk menjalankan aplikasi FastAPI.

3. Frontend Stack:
   - Vanilla HTML, CSS, JavaScript Murni.
   - Deployment: Frontend di-deploy via Vercel.


3. LOGIKA SISTEM (RAG WORKFLOW)
---------------------------------------------------------
1. Dokumen dimasukkan ke `storage/raw_docs/`.
2. `backend/app/main.py` membaca dokumen, mengekstrak teks, dan memecahnya menjadi bagian kecil (chunking).
3. `Nomic Embed Text` mengubah teks menjadi angka vektor dan disimpan secara persisten di `ChromaDB` (storage/vectordb/).
4. Saat User bertanya, interaksi dilakukan melalui antarmuka UI Frontend.
5. Pertanyaan diteruskan oleh Frontend (JSON) ke Backend FastAPI.
6. Backend memproses pencarian konteks terdekat di `ChromaDB` (Semantic Search).
7. Konteks yang ditemukan diberikan ke `Llama 3.2` untuk dirangkum menjadi jawaban akhir dan dikirim kembali ke Frontend.


4. PANDUAN MENJALANKAN PROJECT (LOCAL SETUP)
---------------------------------------------------------
Jika kamu ingin menjalankan project ini di komputer lokal, ikuti langkah-langkah berikut secara berurutan:

LANGKAH 1: PASTIKAN OLLAMA AKTIF (WAJIB)
Karena AI berjalan 100% secara lokal, service Ollama harus dihidupkan terlebih dahulu agar proses RAG berjalan lancar.
- Buka terminal, jalankan:
  ollama serve
*(Biarkan terminal ini terbuka)*

LANGKAH 2: AKTIFKAN VIRTUAL ENVIRONMENT
Buka terminal baru di direktori proyek WYRA-AI-SMARTDOCS, aktifkan virtual environment Python:
- Di Linux/Mac:
  source venv/bin/activate
- Di Windows:
  venv\Scripts\activate

LANGKAH 3: INGEST DOKUMEN (Opsional, Hanya Jika Ada File Baru)
Jika kamu baru saja menambahkan file PDF/DOCX ke dalam folder `storage/raw_docs/`, jalankan ingestion agar data dikenali sistem:
- Jalankan perintah:
  python3 backend/app/main.py

LANGKAH 4: JALANKAN API BACKEND (FastAPI)
Jalankan server API backend agar aplikasi dapat menerima pesan chat dari Frontend:
- Jalankan perintah:
  python3 -m uvicorn main:app --app-dir backend/app --reload

💡 Akses Backend:
- Server Backend berjalan di: http://127.0.0.1:8000
- Swagger/Dokumentasi API: http://127.0.0.1:8000/docs

LANGKAH 5: JALANKAN FRONTEND
- Untuk mencoba UI secara lokal, kamu bisa langsung menjalankan file `frontend/index.html` menggunakan Live Server (ekstensi VS Code).
- Jika UI diakses dari Vercel, pastikan endpoint URL `fetch()` pada file JS mengarah ke alamat backend yang terekspos (misalnya menggunakan Ngrok/localtunnel jika ingin backend lokal dapat diakses Frontend Vercel, ATAU ganti ke domain backend cloud mu).

---
ALTERNATIF: MENJALANKAN MENGGUNAKAN DOCKER
Jika tidak ingin mengatur environment Python secara manual, gunakan Docker:
1. Build Image:
   docker build -t smartdocs-api .
2. Jalankan Container (pastikan Ollama Host sudah running):
   docker run -p 8000:8000 --network="host" smartdocs-api
