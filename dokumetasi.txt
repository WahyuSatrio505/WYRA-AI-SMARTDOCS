2. TEKNOLOGI & TOOLS UTAMA
---------------------------------------------------------
1. AI & RAG Stack:
   - LangChain: Orkestrator yang menghubungkan AI dengan dokumen.
   - Ollama: Menjalankan model AI secara lokal tanpa internet.
   - ChromaDB: Vector Database untuk menyimpan "ingatan" dokumen.
   - Llama 3.2: Otak / LLM utama pembuat jawaban.
   - Nomic Embed Text: Model embedding untuk pencarian kontekstual dokumen.

2. Backend Stack:
   - Python & FastAPI: Framework super cepat untuk melayani API.
   - Uvicorn: Server web untuk menjalankan aplikasi FastAPI.

3. Frontend Stack:
   - Vanilla HTML, CSS, JavaScript Murni.
   - Deployment: Frontend di-deploy via Vercel.


3. LOGIKA SISTEM (RAG WORKFLOW)
---------------------------------------------------------
1. Dokumen dimasukkan ke `storage/raw_docs/`.
2. `backend/app/main.py` membaca dokumen, mengekstrak teks, dan memecahnya menjadi bagian kecil (chunking).
3. `Nomic Embed Text` mengubah teks menjadi angka vektor dan disimpan secara persisten di `ChromaDB` (storage/vectordb/).
4. Saat User bertanya, interaksi dilakukan melalui antarmuka UI Frontend.
5. Pertanyaan diteruskan oleh Frontend (JSON) ke Backend FastAPI.
6. Backend memproses pencarian konteks terdekat di `ChromaDB` (Semantic Search).
7. Konteks yang ditemukan diberikan ke `Llama 3.2` untuk dirangkum menjadi jawaban akhir dan dikirim kembali ke Frontend.


4. PANDUAN MENJALANKAN PROJECT SEBAGAI SERVER VERCEL
---------------------------------------------------------
Agar laptop kamu bisa berfungsi sebagai "Otak/Mesin" yang merespons website yang sudah online di Vercel, kamu WAJIB menyalakan 3 terminal secara bersamaan (jangan di-close terminalnya):

🔥 TERMINAL 1: Nyalakan AI Engine (Ollama)
Pastikan model AI sudah siap melayani permintaan.
- Buka terminal, jalankan:
  ollama serve
*(Jika Ollama sudah berjalan otomatis di background sistem, langkah ini bisa dilewati).*

🔥 TERMINAL 2: Nyalakan Backend Server (FastAPI)
Ini adalah program yang memproses chat dan mencari dokumen di ChromaDB.
- Buka terminal baru (pastikan berada di folder WYRAX SMART DOCS), jalankan:
  source venv/bin/activate
  python3 -m uvicorn backend.app.main:app --reload

🔥 TERMINAL 3: Nyalakan Jembatan Internet (Localtunnel)
Ini berfungsi membuka jalur agar Vercel bisa masuk ke server localhost kamu.
- Buka terminal baru lagi, lalu jalankan:
  npx localtunnel --port 8000 --subdomain wyra-ai-smartdocs

💡 CARA TESTING :
1. Pastikan Ketiga Terminal di atas menyala bersamaan di laptop kamu.
2. Kasih link Vercel kamu (misal: https://wyra-ai-smartdocs.vercel.app atau domain eucalabs) ke temanmu.
3. Saat mereka chat di website tersebut, AI di laptopmu akan otomatis merespons!

---
(Opsional) INGEST DOKUMEN BARU
Jika kamu baru menambahkan file PDF/DOCX ke folder `storage/raw_docs/` dan ingin AI membacanya, cukup buka terminal terpisah lalu jalankan:
  source venv/bin/activate
  python3 backend/app/main.py

---
ALTERNATIF: MENJALANKAN MENGGUNAKAN DOCKER
Jika tidak ingin mengatur environment Python secara manual, gunakan Docker:
1. Build Image:
   docker build -t smartdocs-api .
2. Jalankan Container (pastikan Ollama Host sudah running):
   docker run -p 8000:8000 --network="host" smartdocs-api

2. TECH STACK UTAMA
------------------------------------------------------
[ AI & RAG Workflow ]
- LangChain           : Framework/Orkestrator penghubung dokumen dengan Ollama.
- Ollama              : Engine lokal untuk menjalankan LLM (Llama 3.2 1B) tanpa internet.
- ChromaDB            : Database Vektor (Vector Store) tempat menyimpan "ingatan" dokumen.
- Nomic Embed Text    : Model embedding (mengubah teks jadi vektor agar dipahami mesin). Sangat ringan dan akurat.

[ Ekstraksi Dokumen ]
- PyMuPDF (fitz)      : Parser ekstraksi teks PDF (sangat cepat & stabil di Linux).
- python-docx         : Parser untuk membaca struktur dokumen Word.
- pandas + openpyxl   : Parser untuk merubah tabel Excel menjadi Markdown/String.

[ Software & Backend ]
- FastAPI & Uvicorn   : Framework API Python super cepat (berjalan di port 8000).

[ Frontend & UI ]
- React (Vite)        : Antarmuka utama aplikasi (Landing Page & Dashboard Chat).
- Framer Motion       : Library animasi untuk interaksi UI modern.


3. PANDUAN MENJALANKAN PROYEK LOKAL
------------------------------------------------------
A. Nyalakan Mesin AI (Ollama) -- WAJIB
   Buka terminal, jalankan:
   $ ollama serve
   (Cek dengan `ollama list` untuk memastikan model llama3.2 dan nomic-embed-text tersedia).

*** PENTING UNTUK BACKEND & INGESTION ***
Setiap kali membuka terminal baru untuk menjalankan kode Python, WAJIB aktifkan environment:
$ source venv/bin/activate
*****************************************

B. Memasukkan Data Dokumen ke AI (Ingestion)
   Masukkan file PDF/DOCX ke dalam folder `storage/raw_docs/`.
   Buka terminal di folder root, aktifkan venv, lalu jalankan:
   $ python3 run_ingest.py
   (Catatan: Jika Anda ingin mereset/menghapus memori database lama, jalankan: `rm -rf storage/vectordb/` sebelum ingestion).

C. Nyalakan Backend (FastAPI)
   Buka terminal baru di folder root, aktifkan venv, lalu jalankan:
   $ python3 -m uvicorn main:app --app-dir backend/app --reload
   (API akan berjalan secara asinkron di http://127.0.0.1:8000).

D. Nyalakan Frontend (React UI)
   Buka terminal baru, arahkan ke folder frontend:
   $ cd frontend
   $ npm run dev
   (Buka tautan localhost seperti http://localhost:5173 di browser Anda).


4. PANDUAN DEPLOYMENT (DOCKER / DEVICE LAIN)
------------------------------------------------------
1. Clone Repositori:
   $ git clone https://github.com/WahyuSatrio505/WYRA-AI-SMARTDOCS.git
   $ cd WYRA-AI-SMARTDOCS

2. Persiapkan Ollama:
   $ ollama run llama3.2
   $ ollama pull nomic-embed-text

3. Build & Run Kontainer Docker:
   $ docker build -t smartdocs-api .
   $ docker run -p 8000:8000 --network="host" smartdocs-api


5. CATATAN PENTING CARA KERJA SISTEM RAG
------------------------------------------------------
Sistem Retrieval-Augmented Generation (RAG) bekerja ibarat ujian "Open Book":
1. Saat user bertanya, sistem Retriever (Nomic-Embed) akan mencari paragraf/halaman yang paling relevan dari dalam VectorDB.
2. Paragraf yang ditemukan tersebut akan diberikan kepada LLM (Llama 3.2 1B).
3. LLM bertugas membaca paragraf itu lalu menyusun jawaban akhir untuk user.

Aturan Emas: Jika informasi jawaban TIDAK ADA di dalam dokumen yang diunggah, maka LLM tidak akan bisa menjawabnya. Sistem prompt kita dirancang untuk melarang AI "mengarang" (halusinasi) demi menjaga integritas data perusahaan.
